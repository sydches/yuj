Structural outline or repository symbol lookup; never runs source. With path alone, preserves the single-file Python (.py/.pyi) outline. With repo_wide=true, path names a repository directory and optional symbol is an exact name, kind is def or ref, and page selects a bounded result page. Repository rows are `path:line kind name signature` inside a `<list_definitions mode="repository" ...>` envelope. Both tools.list_definitions.enabled and tools.ast_search_enabled must be on for repository mode. Paths stay inside cwd and configured unreadable paths are skipped. This tool does not change files.
