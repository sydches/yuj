Structural outline or repository symbol lookup; never runs source. With path alone, returns the Python (.py/.pyi) outline or definitions from an installed structural grammar for the requested file. Structural rows use `path:line def name signature` in a `<list_definitions mode="file" ...>` envelope; capped and char_limited report omitted rows. With repo_wide=true, path names a repository directory and optional symbol is an exact name, kind is def or ref, and page selects a bounded result page. Repository rows use the same shape inside a `<list_definitions mode="repository" ...>` envelope. Both tools.list_definitions.enabled and tools.ast_search_enabled must be on for repository mode; single-file mode needs only the first. Paths stay inside cwd and configured unreadable paths are skipped. Missing grammars return explicit errors. This tool does not change files.
