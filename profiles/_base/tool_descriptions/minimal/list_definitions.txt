Structural outline of a single Python source file (.py / .pyi). AST-based; never runs the file. Output wraps in `<list_definitions status="..." path="..." count="N" surface="M" v="1">` on success — body has up to two sections: `# module surface` (imports, `__all__`, `ALL_CAPS = ...`, annotated type aliases) and `# definitions` (one line per class/def with line number, indent matching nesting depth, signature, first-line docstring). Decorators (`@property`, `@dataclass(...)`, etc.) are listed above each def. On failure (disabled / path outside cwd / file not found / unsupported suffix / OS read error / SyntaxError) the envelope shifts to `status="error" error_kind="..."` with the reason in the body — same wrap, same closing tag. Path must be inside cwd. Body content is XML-escaped against `<` `&` `>`. This tool does not change files. Args: path (required, source file). Use BEFORE read() to navigate large files; use read(offset, limit) once you know the line.
