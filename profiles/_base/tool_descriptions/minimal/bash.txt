Run a shell command; returns stdout+stderr. When the schema includes `background`, set it true to return a proc_id immediately, then use bash_poll or bash_kill. Output is normalized (ANSI stripped, blank-line and duplicate-line runs collapsed, secrets redacted) and head/tail-truncated when it exceeds the context budget. Append quiet flags to verbs that emit large logs (e.g. `pip install -q`, `make -s`, `npm install --loglevel=error`) — for some of these the harness already auto-appends a quiet flag. Prefer typed tools when available: `read` instead of `cat`/`head`/`tail`, `glob` instead of `find`, `grep` instead of `rg`/`grep`, `run_tests` instead of test-runner shell commands, and the selected file-edit tool instead of shell redirection. If the active tool profile exposes only `bash` and `done`, mutate source files through bash with a short `python`, `perl`, `sed -i`, `cat >file`, or `tee` command, then run targeted verification.
