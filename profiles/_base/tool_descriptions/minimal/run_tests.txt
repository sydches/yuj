Run the test runner detected from cwd (pytest / cargo / go / jest / ctest) with deterministic flags; default 240s timeout. Output wraps in `<test_results status="..." runner="...">`; it includes `exit_code="N"` when the runner exits and omits it on a timeout or tool error. Status names include `passed`, `failed`, `collection_error`, `internal_error`, `usage_error`, `no_tests_collected`, `timed_out`, and `error`; an unknown exit code uses `error_N`. On `failed` or `collection_error`, the harness inlines ±5 lines around each test frame so you don't need a follow-up `read`. An active finish rule can use a `passed` result as verification. Args: path (file or directory; default cwd), k (test-name expression), last_failed (re-run prior failures with pytest, Jest, or CTest; Cargo and Go ignore it). Prefer over pytest-through-bash — flags are fixed and output is condensed.
