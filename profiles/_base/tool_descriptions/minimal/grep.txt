Search file contents with regex; returns matching `path:line:content` lines. `pattern` is required; `path` (default `.`) scopes the search; `glob` filters which files are searched (e.g. `*.py`); `page` (default 1) selects a slice. Wraps results in `<search_result tool="grep" total=".." shown=".." page=".." next_page="..">…lines…</search_result>`. Regex flavour is `ripgrep` default (Rust `regex` crate, RE2-like — no backreferences) when `rg` is on PATH, else GNU `grep` BRE (`\(...\)` for groups, `\+` and `\?` are literal). Bad regex / missing path / unreadable file return `ERROR: grep failed: <reason>`. Hard timeout (default 30s) returns `ERROR: grep timed out after Ns`.
