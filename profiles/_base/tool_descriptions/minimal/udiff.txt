Apply a standard unified diff to files inside the working directory. Pass the complete diff in `patch`, including `---` and `+++` file headers and one or more `@@ -old,+new @@` hunks. Prefix unchanged lines with one space, removed lines with `-`, and added lines with `+`. Use `/dev/null` for file creation or deletion. Yuj verifies every file before writing, accepts a uniquely matching hunk when line numbers or whitespace have drifted, and returns exact near-miss candidates when a hunk cannot be placed safely.
